# Orchard Core 1.6.0

发布日期：尚未发布

## 重大变更

### 用户

`OrchardCore.Users` 模块现在提供多个新权限，用于对用户相关功能进行更精细的控制。

之前的版本中，`View Users` 权限足以显示 `Users` 菜单项。但是，通过新增的权限，现在需要 `ListUsers` 或至少一个 `ListUsersInRole_{0}` 变体才能查看 `Users` 菜单。`View Users` 权限现在仅允许查看用户的个人资料。`ManageUsers` 是超级用户权限，允许管理用户的所有权限，包括用户设置。

下面是新权限列表：

| 权限名 | 描述 |
| --- | --- |
| `ListUsers` | 允许列出所有用户。 |
| `EditUsers` | 允许编辑任何用户。 |
| `DeleteUsers` | 允许删除任何用户。 |
如果启用了 `OrchardCore.Roles` 功能，将提供以下权限:

| 权限 | 描述 |
| --- | --- |
| `AssignRoleToUsers` | 允许将任何角色分配给用户。 |
| `ListUsersInRole_{0}` | 允许列出给定角色中的用户。 |
| `EditUsersInRole_{0}` | 允许编辑给定角色中的用户。 |
| `DeleteUsersInRole_{0}` | 允许删除给定角色中的用户。 |
| `AssignRoleToUsers_{0}` | 允许将用户分配给给定角色。 |

### `OrchardCore.Search` 模块

`SearchSettings` 类中的属性 `SearchProviderAreaName` 已重命名为 `ProviderName`。如果您同时在使用 `Lucene` 和 `Elasticsearch` 搜索服务提供程序，则需要通过将默认搜索服务提供程序设置为两者之一来更新搜索设置。

此外，`SearchFormViewModel`，`SearchIndexViewModel` 和 `SearchResultViewModel` 的命名空间由 `OrchardCore.Search.Abstractions.ViewModels`更改为 `OrchardCore.Search.ViewModels`。

`SearchSettings` 类的命名空间从 `OrchardCore.Search.Model` 更改为 `OrchardCore.Search.Models`。

### 功能和食谱
`OrchardCore.Features` 已不再由 `OrchardCore.Recipes` 自动启用，因为它不再依赖于它。如果您在您的模块中使用 `IRecipeMigrator` 等配方服务，请务必在您的模块清单文件中添加对 `OrchardCore.Recipes.Core` 功能的依赖，以确保配方服务在使用它们之前可用。

如果您正在使用设置配方并希望启用 `Features`，请确保显式启用 `OrchardCore.Features` 功能。

## 更改日志

### 新的 `OrchardCore.Notifications` 模块
添加了新功能，提供了一种向用户发送通知消息的方式。有关通知的更多信息，请单击此处。

### `OrchardCore.Contents` 模块
在此版本之前，具有 `ViewContent` 权限并可以访问仪表板的用户会自动访问 “内容项”。现在，要在仪表板上列出内容，用户需要 `ListContent` 权限。

### `TheAdmin` 主题设置

将允许您根据屏幕大小使管理主题具有响应性，添加新的设置到 `TheAdmin` 主题中。

例如，在 `appsettings.json` 文件中添加以下设置将生成下面的屏幕截图： 

```json
{
    "OrchardCore": {
    "TheAdminTheme": {
        "StyleSettings": {
        "WrapperClasses": "row mb-3",  // 包装类
        "LimitedWidthWrapperClasses": "row",  // 有限宽度包装类
        "LimitedWidthClasses": "col-md-6 col-lg-5 col-xxl-4",  // 有限宽度类
        "StartClasses": "col-lg-2 col-xl-3",  // 开始类
        "EndClasses": "col-lg-10 col-xl-9",  // 结束类
        "LabelClasses": "col-form-label text-lg-end col-lg-2 col-xl-3",  // 标签类
        "OffsetClasses": "offset-lg-2 offset-xl-3"  // 偏移类
        }
    }
    }
}
```

为了让自定义部件或字段编辑器与新的设置协同工作，必须更新视图以使用新的辅助工具。

1.调用“Orchard.GetInputWrapperCssClasses（）”助手以获取输入包装器的适当CSS类。
2.调用`Orchard.GetLabelCssClasses（）`助手以获取标签元素的适当CSS类。
3.将对应于标签的所有元素包装在像`div`之类的元素中进行分组。然后使用`Orchard.GetEndCssClasses（）`助手获取新`div`的正确CSS类。

例如，`TitlePart.Edit.cshtml`视图已更改为

```

    <input asp-for="Title" class="form-control content-preview-text content-caption-text" disabled="@(Model.Settings?.Options == TitlePartOptions.GeneratedDisabled)" autofocus="autofocus" dir="@culture.GetLanguageDirection()" />
    <span asp-validation-for="Title"></span>
    @if (! String.IsNullOrWhiteSpace(Model.Settings?.Pattern))
    {
        switch (Model.Settings?.Options)
        {
            case TitlePartOptions.Editable：
                <span class="hint">@T["Leave empty to auto-generate the title using the pattern."]</span>
```

将上述代码翻译为：

```
<!-- 在包装元素中，我们使用 GetWrapperCssClasses() 辅助方法获取适当的类。-->
<div class="@Orchard.GetWrapperCssClasses()" asp-validation-class-for="Title">
    <!-- 在标签元素中使用 GetLabelCssClasses() 辅助方法。-->
    <label asp-for="Title" class="@Orchard.GetLabelCssClasses()">@T["Title"]</label>

    <!-- 添加此 div 以分组相应的元素。另外，使用 GetEndCssClasses() 获取适当的类。-->
    <div class="@Orchard.GetEndCssClasses()">
        <input asp-for="Title" class="form-control content-preview-text content-caption-text" disabled="@(Model.Settings?.Options == TitlePartOptions.GeneratedDisabled)" autofocus="autofocus" dir="@culture.GetLanguageDirection()" />
```
下面是所有添加的辅助方法的列表：

| 辅助函数 | 描述 |
| --- | --- |
| `Orchard.GetWrapperCssClasses()` | 获取外包装元素的CSS类。 |
| `Orchard.GetLabelCssClasses()` | 获取标签元素的CSS类。 |
| `Orchard.GetStartCssClasses()` | 获取起始部分的CSS类。例如，如果要将元素向结尾推送以与标签对齐。 |
| `Orchard.GetEndCssClasses()` | 获取结束部分的CSS类。 |
| `Orchard.GetEndCssClasses(bool withOffset)` | 获取带偏移量的结束部分的CSS类。 |
| `Orchard.GetOffsetCssClasses()` | 获取偏移类以对齐结尾元素。 |
| `Orchard.GetLimitedWidthWrapperCssClasses()` | 获取带有限制宽度的元素包装器元素的CSS类。 |
| `Orchard.GetLimitedWidthCssClasses()` | 用于具有限制宽度的字段，如“数字”元素。例如，查看`NumericField.Edit.cshtml`视图。 |

### `OrchardCore.Search` 功能
添加了新的“搜索表单”小部件，允许您将搜索表单作为小部件添加到您的站点中。

除了默认的`/search`路径外，您现在可以使用`/search/{indexName}`，其中`{indexName}`是您的搜索索引的名称。

添加了以下视图，以便根据需要更简单地覆盖视图

- `Search-List.cshtml`呈现搜索页面。
- `Search-Form.cshtml`呈现搜索表单的表单。
- `Search-Results.cshtml`在执行搜索后呈现搜索结果。
当使用 `Search Form` 时，`SearchFormPart.cshtml` 渲染搜索表单。
