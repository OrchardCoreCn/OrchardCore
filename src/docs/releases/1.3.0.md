# Orchard Core 1.3.0

发布日期：2022年3月

此版本包含安全漏洞修复。建议您使用此版本更新现有的Orchard Core部署。

## 不兼容变更

此版本不再支持netcoreapp3.1和net5.0。仅支持net6.0。
