# Orchard Core 1.0.0-rc2

发布日期：2020年6月 

[将此版本与上一个版本进行比较](https://github.com/orchardcms/orchardcore/compare/1.0.0-rc1...1.0.0-rc2)

## 破坏性变化

- .NET Core 3.1
- 将默认的BagPart从Detail更改为Summary。
- 电子邮件现在根据RFC区分提交者和发送者。
- Lucene索引设置现在存储在数据库中，并且数据JSON模式已更改，因此需要重新配置索引。

## 里程碑

[RC2](https://github.com/OrchardCMS/OrchardCore/milestone/10)

## 新功能

- 新的orchardcore.net域名(docs，try)
- 新的管理员界面，用于批量操作
- 新的管理员菜单结构
- 新的文档结构
- 解决方案中的文档项目
- 升级到MkDocs Material 5
- 使用 all-contributors 生成贡献者列表
- 自定义管理员URL前缀
- 部署计划配方导出
- 全文搜索增强
- 在分类法中打开标签编辑器
- 包含项目路由
- 内容选择器菜单
- 安装页面上的语言选择器
- 屏幕设置适应小分辨率
- autoroute和alias的默认模式
- 显示模式选项
- 过滤管理员菜单
- 流程编辑器UI改进
- 切换所有Widgets按钮
- 在ListPart中排序项目
- 检索、更新内容工作流任务
- 禁用和启用租户工作流任务
- 用户禁用/启用事件
- 用户可以更改电子邮件
- 禁用用户帐户
- 允许在 HTML 中插入图像
- 供应商前缀的主题
- ConsoleLog 帮助程序
- 预览功能改进
- Trumbowyg 编辑器、设置和插件
- 添加根据模式生成显示文本的功能
- 数据库和 Azure Blob shell 配置
- 无密码的外部登录注册
