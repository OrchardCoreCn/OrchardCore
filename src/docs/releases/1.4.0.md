# Orchard Core 1.4.0

发布日期：2022年6月

此版本包含安全漏洞修复，请建议您将现有的Orchard Core部署更新到此版本。

## Breaking Changes（重大更改）

* 默认情况下，不再允许在经过验证的内容中使用`<form>`标签https://github.com/OrchardCMS/OrchardCore/pull/11729
